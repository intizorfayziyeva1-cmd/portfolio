## 📖 Loyiha haqida

**MyPortfolio** — veb-dasturlashni o'rganayotgan muallif tomonidan **HTML** va **CSS** yordamida noldan yaratilgan shaxsiy portfolio sayti. Sayt o'zbek tilida bo'lib, muallifning o'zi, qiziqishlari va loyihalari bilan tanishtiradi.

Dizayn qorong'i fon va moviy (`#38bdf8`) urg'u rangiga asoslangan bo'lib, silliq o'tishlar (hover effektlari) va barcha qurilmalarga moslashuvchan (responsive) tuzilmaga ega.

## ✨ Imkoniyatlari

- 🧭 **Navigatsiya paneli** — bo'limlar orasida silliq (smooth scroll) o'tish
- 🦸 **Hero bo'limi** — salomlashuv, kasb va "Loyihalarimni ko'rish" tugmasi
- 👤 **"Men haqimda" bo'limi** — qisqacha tanishtiruv
- 🗂️ **Loyihalar kartochkalari** — hover paytida yuqoriga ko'tariladigan va ramkasi yonadigan 3 ta karta
- 📬 **Aloqa bo'limi** — elektron pochta orqali bog'lanish
- 📱 **Responsive dizayn** — telefon, planshet va kompyuter ekranlariga moslashadi (`max-width: 768px` uchun alohida qoidalar)

## 🚀 Ishga tushirish

Loyihani kompyuteringizda ochish uchun hech qanday o'rnatish talab qilinmaydi.

**1. Repozitoriyni yuklab oling**

```bash
git clone https://github.com/intizorfayziyeva1-cmd/portfolio.git
```

**2. Papkaga kiring**

```bash
cd portfolio
```

**3. Saytni oching**

`index.html` faylini brauzeringizda ikki marta bosib oching.

### 🌍 GitHub Pages orqali joylashtirish

1. Repozitoriyning **Settings** → **Pages** bo'limiga kiring
2. **Source** qismida `main` branch va `/ (root)` papkasini tanlang
3. **Save** tugmasini bosing — bir necha daqiqadan keyin sayt `https://intizorfayziyeva1-cmd.github.io/portfolio/` manzilida ochiladi
